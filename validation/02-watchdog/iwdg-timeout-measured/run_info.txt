Build flag: VALIDATION_IWDG_STARVE_TEST (task_watchdog.c), BTN6 trigger.
On BTN6 press, WatchdogTask permanently stops calling HAL_IWDG_Refresh()
regardless of alive_mask ("[TRIGGER] IWDG refresh starved") — this measures
the raw IWDG timeout, independent of any specific task's alive-mask logic.

IWDG config (Core/Src/main.c, MX_IWDG1_Init): Prescaler=/32, Reload=500,
Window=4095 (window disabled). Theoretical timeout = 32 * (500+1) / f_LSI
= 16032 / 32000 Hz (nominal) = 501ms.

Theoretical vs measured: 501ms (nominal 32kHz LSI) vs 410.35ms measured ->
implied real LSI ~= 501/410.35 * 32000 ~= 39082 Hz ~= 39.1kHz. The LSI RC
oscillator is not factory-trimmed on this part; a gap of this size is within
its documented tolerance and is not a firmware bug.
